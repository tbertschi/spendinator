# Spendinator

A smartphone application for managing your monthly budget with visual tracking and categorized expense management.

## Features

- **Visual Budget Tracking**: A progress graph showing your budget evolution since the start of the month
- **Category Dashboard**: 8-tile grid (2x4) displaying budget categories (transport, meals, leisure, etc.)
- **Expense Management**: View and add expenses for each category with date, description, and amount
- **Budget History**: Navigate through the last 12 months to review previous spending patterns

## App Structure

- Top quarter: Budget evolution graph (relative to initial monthly allocation)
- Main area: 2-column × 4-row grid of category tiles showing spent amounts
- Detail view: Per-category expense lists with add functionality

## Target Platform

Optimized for smartphone portrait orientation.
